Cara Bergabung

1

Dapatkan Minecraft

Unduh dan instal Minecraft Java atau Bedrock Edition di perangkat Anda.

2

Salin Detail Koneksi

Gunakan informasi IP dan port server di atas (klik tombol salin untuk akses mudah).

3

Tambah Server

Buka Minecraft, masuk ke Multiplayer, klik "Tambah Server" dan tempel detail koneksi.

4

Bergabung & Mainkan!

Klik "Bergabung Server" dan mulai petualangan Anda di Ryzoria SMP!
